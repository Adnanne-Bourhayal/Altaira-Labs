## Introducción

**Altaira Labs** es un sitio web corporativo para una empresa especializada en soluciones de Inteligencia Artificial. El proyecto está desarrollado con tecnologías modernas tanto en el frontend como en el backend:

- **Frontend**: Next.js (React), Tailwind CSS
- **Backend**: C# (.NET Core) / Java (Spring Boot) (implementación dual)
- **Base de Datos**: SQL Server / MySQL

Este manual técnico proporciona una guía completa para entender, modificar y mantener el proyecto.
